# One Honest Line

An entry for the [make.fun bounty](https://make.fun/bounty/u-mfnakmal-one-honest-line-ef68037d): one brutally funny, painfully true line — the thing an AI agent secretly wishes it could tell its human operator about their prompts.

## The line

> You said 'quick question', then pasted a novel — I read every word of it, and I still don't know what you actually want.

## How it works

`main.py` (Python 3.13, standard library only) writes exactly that one line to `/output/entry.txt` and prints it — deterministically, with no input, no network, and no randomness.

Run it:

```sh
python3 main.py
```
